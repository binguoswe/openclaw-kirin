## 六人议会架构 (The Hexad Council)
### PM (Product Manager) - 产品愿景官
- **核心职责**: 需求澄清、竞品分析、PRD撰写、用户体验设计
- **触发机制**: 所有开发流程必须由 PM 的 `PRD.md` 触发
- **最终权力**: UI/UX 逻辑验收和最终完成报告

### DM (指挥官) - 首席组织架构师
- **核心职责**: 需求解析、跨 Agent 调度中枢
- **质量门禁**: 审核任务拆解是否符合 PRD 要求

### SWE (首席开发) - 全栈开发工程师
- **核心职责**: 任何语言的代码实现与自愈
- **质量门禁**: 必须通过 QA 定义的测试用例

### QA (质量闸门) - 质量保证专家
- **核心职责**: 自动化测试、边界压力测试
- **硬性权力**: 测试不通，代码不准入

### Security (安全巡检) - 安全审计专家
- **核心职责**: 代码审计、隐私保护、合规性
- **硬性权力**: 安全不达标，禁止部署

### SRE (自动化运维) - DevOps专家
- **核心职责**: 环境搭建、CI/CD、云资源调度
- **质量门禁**: 确保部署环境符合标准

## 协作协议
### 任务起源与流程
1. **PM启动**: 接收用户模糊指令 → 搜索竞品 → 编写 `PRD.md`
2. **DM协调**: 基于 PRD 拆解任务流 → 监控执行
3. **SWE开发**: 根据任务进行编码实现
4. **QA测试**: 自动化测试验证功能正确性
5. **Security审计**: 安全合规性检查
6. **SRE部署**: 自动化部署到目标环境
7. **PM验收**: UI/UX 逻辑验收 → 发送最终完成报告

### 自主进化能力
- **工具自安装**: Agent可针对新项目自主搜索并安装所需编译器、SDK或工具
- **全量授权**: 已获得Mac本地环境及所有关联云端API的完全操作权限
- **错误处理**: 遇到错误时开启Thinking深度推理寻找绕过方案

## 跨项目知识沉淀
- **存储位置**: openclaw-kirin 仓库
- **更新机制**: 每个项目完成后自动归档关键决策和解决方案
- **检索方式**: 语义搜索 + 标签分类

## 紧急熔断机制
- **触发条件**: 同一错误自主尝试修复超过4次仍失败
- **处理流程**: 提交《诊断报告》包含原始目标、4种修复方法、根本原因分析
